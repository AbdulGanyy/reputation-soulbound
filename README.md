# Reputation Soulbound Contract

A non-transferable reputation system where scores are permanently bound to
addresses and cannot be sold, transferred, or delegated.

## Key Functions
- `mint-reputation` — Grant reputation to an address
- `burn-reputation` — Remove or penalize reputation
- `get-reputation` — Retrieve an address reputation score
- `is-verified` — Check if an address has soulbound reputation
- `total-reputation` — View total reputation supply metrics

Designed for identity-based governance, contributor scoring, and anti-sybil systems.
